本地目录包含子目录中的基础副本和外层继续修改的实践版本。本文以这两份文件的实际差异为依据，没有找到原始 `.git` 历史，无法给出上游提交 SHA，也不能确认基础副本此前是否已有本地修改。

2026-11-01 整理时，原项目页面和 API 读取返回 404，未能与上游远端当前版本对照。这只能说明本次无法读取，不能判断原项目已删除。原有链接与署名仍保留。

[`upstream-local-snapshot` 分支](https://github.com/shaoyeaichangge/phone-speaker-bridge/tree/upstream-local-snapshot)记录本地基础副本的导入，不是上游原始提交；该导入提交由本仓库维护者创建。逐文件 SHA-256 见 [source-manifest.json](source-manifest.json)，基础 README 保存在 [README.upstream.md](README.upstream.md)。

## 已能确认的本地扩展

### 采集异常后的重试

基础副本的 `LoopbackCapture._run()` 在读取音频出现 `OSError` 后退出线程。实践版本增加关闭失效流并重新打开同一设备的逻辑，每秒重试、每轮最多 30 次，失败后继续下一轮尝试。静音填充与 RTP 调度来自基础实现。

这项扩展针对同一设备的暂时故障，不会自动跟随新的默认设备，也没有改变缓冲策略。发布版保留这一改进。

### 重复启动与端口占用处理

实践版本增加 `netstat -ano`、PowerShell `Stop-Process`、等待和启动提示，本地修补脚本可印证相关语法和时机调整。旧逻辑按端口子串匹配并强制结束进程，可能波及其他程序。

本次发布用尝试绑定目标端口的方式检查占用，给出换端口提示，不再终止其他程序。`--list-devices` 在端口检查前执行，不影响现有服务。

### 启动脚本与桌面快捷方式

外层实践版本包含 `.cmd`、`.bat` 和快捷方式生成器。其中 `.cmd` 使用相对路径，其他脚本写死了维护者的本机目录。

发布版统一为 `start.cmd`，负责创建独立环境、安装依赖、传递参数和保留错误窗口；旧文件名保留为兼容入口。快捷方式自动取得脚本位置和当前用户桌面。

基础副本也保留了带自动安装逻辑的 `start.cmd`，无法确认其来源是上游还是先前的本地辅助工作。因此不把“首次安装依赖”这一思路声称为原创，只说明本次发布的统一实现。

## 继承而非新增的部分

- WASAPI 回环采集、20 ms 音频帧、WebRTC / Opus 与信令接口。
- Listen 与 Mic 模式、手机麦克风反向播放。
- 有界队列、丢弃旧数据、静音持续发送与连续 RTP 时间戳。
- 自签名 HTTPS、局域网地址展示、多客户端能力。
- 网页布局、按钮、缓冲统计、屏幕唤醒请求。

两份 `index.html` 字节完全一致，网页界面不列为本地新增成果。

增加中文说明、来源对照、通用启动路径、端口检查、单元验证、忽略本机文件规则，以及历史补丁和哈希清单。没有把本机证书、私钥、依赖目录、日志与无关文件放入仓库。
